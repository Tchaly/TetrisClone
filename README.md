# TetrisClone
Python3 version of tetris (no sound)

# Directionnal controls :
left : goes left with the piece, amène la pièce à gauche
right : goes right with the piece, amène la pièce à droite
up : rotate the piece, tourne la pièce
down : make the piece directly down, amène la pièce au sol
